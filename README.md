# Portfólio — Tainá Alecrim

Site pessoal de apresentação profissional, desenvolvido com HTML, CSS e JavaScript puro.

## Estrutura
- `index.html`: versão em português.
- `en/index.html`: versão em inglês.
- `styles.css`: identidade visual, layout e responsividade.
- `script.js`: menu mobile e ano automático no rodapé.
- `assets/`: ilustração do hero e favicon.

## Publicação com GitHub Pages
1. Abra **Settings** do repositório.
2. Acesse **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`; salve.
5. Aguarde o GitHub Pages publicar o endereço do site.

Endereço esperado: https://tainalecrim.github.io/portifolio-taina-alecrim/

## Atualizações
Edite `index.html` e `en/index.html` para atualizar os textos e projetos nas duas versões. Os projetos foram organizados em cards para que novos trabalhos possam ser adicionados conforme evoluírem.
